# Equation Solver
一元多项式方程计算工具，可以解二到四次方程  
A tool for solving equations from quadratic equation to quartic equation  

1. 一元四次方程 Quartic equation
$ax^4+bx^3+cx^2+dx+e=0$  
使用笛卡尔法求解  
Solve by *Descartes's method*  

2. 一元三次方程 Cubic equation
$ax^3+bx^2+cx+d=0$  
使用卡尔达诺公式求解  
Solve by *Cardano formula*  

3. 一元二次方程 Quadratic equation
$ax^2+bx+c=0$
